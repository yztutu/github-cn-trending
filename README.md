# GitHub 中文热门日报

每天追踪 GitHub 热门榜（Trending），专挑**中文项目**，每个项目配一句基于其真实简介的中文点评，帮你快速发现值得关注的国产/中文开源项目。

- 数据来源：GitHub Trending 日榜与周榜
- 中文项目判定：仓库简介中含有中文字符
- 更新方式：由 `generate.py` 抓取生成（`fetch` 抓榜单 → `build` 出日报）
